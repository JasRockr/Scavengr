🗃️ Scavengr

"Descubre lo que tus bases esconden."

Herramienta de línea de comandos que lee los metadatos de PostgreSQL, MySQL/MariaDB y SQL Server y genera DBML, un diccionario de datos con la sensibilidad de cada columna y un informe de calidad del esquema.

📚 Documentación 🚀 Empezar 📁 GitHub

🚀 Características Principales

Extrae esquemas, genera DBML, crea diccionarios y produce informes analíticos

🔍

Extracción de Metadatos

PostgreSQL, MySQL/MariaDB y SQL Server. Lee tablas, columnas, tipos, llaves primarias y foráneas e índices, y los escribe en DBML.

📊

Diccionario de Datos

Excel, CSV o JSON con 19 campos por columna: descripción, regex, máscara, ejemplos, módulo y sensibilidad (de BAJO a CRÍTICO), decidida por el nombre de la columna.

✅

Validación de Esquemas DBML

Revisa que el DBML se pueda parsear, que las tablas tengan columnas y PK, y que las relaciones apunten a columnas que existen. Avisa de patrones típicos de cada motor.

📈

Informe de Calidad

Puntuación de calidad (completitud, integridad referencial, nombres y documentación), distribución de tipos, sensibilidad y recomendaciones, en Excel o JSON.

⚡

Caché de Metadatos

Con --cache, guarda lo extraído durante 24 horas y lo reutiliza en vez de volver a consultar la base.

✅ Flujo de Trabajo Típico

Configuración simple y comandos intuitivos

1. Configuración Inicial

# Una sola vez
scavengr init

2. Extraer Esquema

scavengr extract -o schema.dbml

3. Validar

scavengr validate -i schema.dbml

4. Documentar

scavengr dictionary -i schema.dbml -o dict.xlsx

⚡ Instalación

Python 3.11 o superior, con el extra del motor que vas a usar

Desde PyPI (Recomendado)

# PostgreSQL; también [mysql], [mssql] o [all-db]
pip install "scavengr[postgres]"

# Verificar instalación
scavengr --version

# Configuración inicial
scavengr init

Desde Fuente (Desarrollo)

# Clonar repositorio
git clone https://github.com/JasRockr/Scavengr.git
cd Scavengr

# Instalar en modo desarrollo
pip install -e ".[dev,postgres,mysql,mssql]"

🎯 Uso Básico

Comandos principales y ejemplos prácticos

Configuración Rápida

# Generar archivo .env automáticamente
scavengr init

# O configuración global
scavengr init --global

Extraer y Validar

# Extraer esquema completo
scavengr extract -o mi-esquema.dbml

# Con caché de 24 horas
scavengr extract --cache -o mi-esquema.dbml

# Validar estructura
scavengr validate -i mi-esquema.dbml

Generar Documentación

# Diccionario de datos
scavengr dictionary -i schema.dbml -o diccionario.xlsx

# Reporte analítico
scavengr report -i schema.dbml -o reporte.xlsx

⚠️ Estado del Proyecto

Scavengr está en alfa. Una auditoría técnica de octubre de 2026 encontró fallos que dan resultados incorrectos sin avisar, y los estoy corrigiendo en la versión 0.0.5.

Limitaciones conocidas

Se ignoran el puerto y el driver configurados; en PostgreSQL, las llaves foráneas pueden salir mal y un usuario de solo lectura no ve PK ni FK; las columnas camelCase se pierden entre pasos; y la clasificación de sensibilidad detecta pocas columnas personales.

Cómo lo estoy probando

Cada arreglo lleva una prueba contra un laboratorio con PostgreSQL, MariaDB y SQL Server reales, y el DBML se valida con el parser oficial. El CI corre en Python 3.11 a 3.14.

Más detalle

La lista completa y el plan hasta la v1.0 están en la auditoría técnica y en el README.
